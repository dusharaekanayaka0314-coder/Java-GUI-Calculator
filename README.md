# 🧮  Java-GUI-Calculator

A clean and simple **desktop calculator application** developed using **Java Swing** in NetBeans.  
This project demonstrates GUI design, event handling, and basic arithmetic logic in Java.


## 🚀 Features
- ➕ Addition  
- ➖ Subtraction  
- ✖ Multiplication  
- ➗ Division  
- 🧹 Clear (C) button  
- ⌨ Keyboard input support  
- 🖱 Button-based input  
- 🎨 Simple and clean GUI design  

---

## 🛠️ Technologies Used
- ☕ Java  
- 🖼 Java Swing  
- 💻 NetBeans IDE

## ▶️ How to Run

### Option 1: Using NetBeans
1. Open the project in NetBeans  
2. Run the `calculaterInterface.java` file  

### Option 2: Using JAR file
1. Download the exported `.jar` file  
2. Double-click to run the application
